# موقع شخصي ثابت على GitHub Pages

هذا المشروع يستخدم HTML وCSS وJavaScript فقط، ويمكن نشره مباشرة على GitHub Pages دون PHP أو قاعدة بيانات.

## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub.
2. من إعدادات المستودع افتح **Pages**.
3. اختر النشر من الفرع الرئيسي ومجلد الجذر، ثم احفظ الإعداد.
4. افتح الرابط الذي يعرضه GitHub Pages بعد اكتمال النشر.

## التخصيص
- عدّل بيانات الصفحات والاسم ووسائل التواصل في ملفات HTML في جذر المشروع.
- أضف أو عدّل المشاريع في `data/projects.json`، وضع الصور ضمن `assets/img/`.
- عدّل التصميم في `assets/css/styles.css` وسلوك الواجهة في `assets/js/main.js`.

## حدود النسخة الثابتة
- صفحات GitHub Pages لا تنفّذ PHP؛ لذلك أزيلت لوحة الإدارة الخادمية.
- نموذج التواصل يفتح تطبيق البريد لدى الزائر ولا يحفظ الرسائل على الموقع. لحفظ الرسائل يلزم استخدام خدمة نماذج خارجية أو خادم خلفي.
- يمكن فتح `index.html` مباشرة للعرض، لكن تحميل بيانات المشاريع عبر `fetch` يحتاج خادماً محلياً أو استضافة GitHub Pages. للتجربة المحلية شغّل خادماً ثابتاً من جذر المشروع، مثل `python3 -m http.server 8000`.
